# 2026-10-05 Phase 1 実装メモ

## 実装

- Rust単一crateを作成。
- Tokio + AxumでHTTP/WebSocketサーバを実装。
- /healthz と /ws/audio を追加。
- Opus codec adapterを8 kHz mono / 60 ms / 480 samplesに固定。
- hello / audio_config / room_join / room_leave の最小control protocolを追加。
- roomごとのparticipant registryと送信元を除く音声fan-outを追加。
- 音声送信キューを8 packetのbounded channelにし、slow receiverではpacketをdropする。
- SIGINT / SIGTERMでgraceful shutdownする。

## 互換性

既存Python serverが受け取っていた /ws/audio のbinary Opus packetを最初の互換境界として維持した。
Discord VCへの変換はPhase 1から削除し、同じroomにいるWebSocket sessionへ直接fan-outする。

## 検証状況

- 現行Python serverを読み、8 kHz mono Opus / 60 ms / 480 samplesを確認。
- Rust/Cargo toolchainが現在の実行環境に入っていないため、cargo test / cargo check は実行できなかった。
- libopusの存在確認もtoolchain未導入のため実行結果を確定できていない。

## 次の作業

- Rust stable toolchain + libopusのある環境でcompile/test。
- Piの実データfixtureを使った互換試験。
- 実機で再接続、packet loss、jitter、遅延を計測。
